# SystemLink CLI

SystemLink CLI manages saved connections to SystemLink environments and the credentials used to authenticate them.

## Language

**Profile**:
A named SystemLink connection with server locations, authentication preferences, and optional workspace defaults.

**Credential Store**:
The selected location for a profile's authentication secrets: the operating-system credential store or the configuration file.

**Profile Credential Replacement**:
A change to a saved profile and its authentication secrets that preserves the previously usable profile until its replacement is saved.
