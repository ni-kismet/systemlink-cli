Managed-client test minions now store the REST connection delivered by the Salt master (`http` pillar) in their state directory and use it for health tag publishing, so no pre-allocated API key or profile is required. Health tags now verify TLS with the delivered certificate, and minions advertise a `host`/`alias`/`fqdn` identity so the UI shows a System Name. The new `--simulated` option (default `true`) selects simulated identity and health values; `--simulated false` uses the local host's name, OS, CPU, memory, and disk values.
