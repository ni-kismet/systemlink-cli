`slcli managed-client run --simulated false` now runs software jobs against the host's package manager on Debian-family Linux distributions (such as Ubuntu) using `dpkg-query` and `apt-get`. Package inventory, installs, removals, repository listing, and reboot checks read the real host. Simulated mode (the default) keeps the isolated mock. Other hosts return `unsupported-host-package-manager` for package jobs.
