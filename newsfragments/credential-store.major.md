New logins store API keys and PKCE credentials in the operating system's credential store by default, with an explicit file-store option and a warned file fallback when OS storage is unavailable. Add `slcli config secure` for existing plaintext profiles. Remove legacy global keyring reads and `slcli config migrate`; users who relied only on those entries, or on older per-token PKCE credentials, must run `slcli login` again to configure a profile. To remove obsolete macOS Keychain items manually, run `security delete-generic-password -s systemlink-cli -a <ACCOUNT>` for each of `SYSTEMLINK_API_KEY`, `SYSTEMLINK_API_URL`, `SYSTEMLINK_WEB_URL`, and `SYSTEMLINK_CONFIG`.
